# English field labels and source identifiers

All documentation, script messages and package filenames use English. Personal names and the institution's official name retain their original spelling. Source filenames, worksheet names, column identifiers and categorical values retain their exact original spelling where required to read the external archive or join existing results. These are data keys, not untranslated instructions.

The labels below translate the working-table identifiers; they do not establish anatomical equivalence with ANSUR II, NHANES or case measurements. In particular, the bimalleolar and calf fields retain the uncertainties described in DATA.md. The CSV dictionary records units and model roles.
